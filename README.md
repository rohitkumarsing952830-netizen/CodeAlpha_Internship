# CodeAlpha Network Sniffer

## About
This project is a basic network packet sniffer developed as part of my CodeAlpha Internship.

## Features
- Captures network packets
- Displays source IP address
- Displays destination IP address
- Displays protocol information
- Displays packet length
- Displays source and destination ports
- Identifies TCP and UDP traffic

## Technologies Used
- Python
- Socket
- Scapy

## Project Output
The program captures network packets and displays useful packet information such as IP addresses, ports, protocol and packet length.
